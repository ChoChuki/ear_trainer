# Ear Trainer 3.0.10 · 统一训练版

## 3.0.10 修复

- One Note 的 Buttons 答后试听必须手动选择一个音名和一个八度，顺序不限；只按其中一个或连续按同类键不会发声。每次完整组合后清空选择，下次必须重新按两个键。未完成组合时标记所选键；超出乐器实际音域的组合不发声、不替换为其他音高。
- 第一次选择即暂停自动下一题，试听不计分。Next / Replay / Stop 等取消音频的操作清除未完成的组合。正常作答、设置页直接音高 Preview、乐器键位试听、Two Notes 与盲测保持原样。
- 普通版、单文件版及离线缓存同步更新。`tests/browser_button_review.py` 在普通版和单文件版的钢琴、小提琴四组均通过；`tests/test_button_review.cjs` 覆盖所有实际音域内外的组合。完整旧版回归测试未全部执行。

## 3.0.9 修复

- 修复停止训练后 Start practice 下方仍然显示答题键盘的问题。One Note / Two Notes 的设置页不再显示任何答题键盘（音名、八度、半音数字、琴键或指板），无论是否存在上一轮成绩。Stop 后清除旧答题按钮，保留成绩、历史及 One Note 手动 Preview。真正的 Free Play 仍显示完整乐器。
- 每题回答完成、尚未停止整轮训练时，普通练习的自由试听、重播、答错暂停、Next 及整体布局全部保持不变。此前版本关于 Stop 后保留答题区的说明由本版本取代。
- 普通版、单文件版和 PWA 缓存同步更新。

## 3.0.8 修复

- 仅调整训练界面布局：Stop / Next / Replay、成绩与反馈、Other 等作答辅助按钮以及实际作答区组成一个连续的操作区。按屏幕剩余高度将整个操作区布置在略偏下的中间位置，空白只分配在操作区外部，不再将控制栏固定在顶部、答题键推到底部。
- 保留原有控件顺序、按键大小、训练与试听规则。屏幕空间不足时不强制压缩键位，允许整个页面自然纵向滚动。
- 两种训练模式、两种乐器和两种答题界面均适用；普通版、单文件版和离线缓存同步更新。

## 3.0.7 修复

- One Note 题间干扰音减为随机 3–4 个（原 6–8 个），每音仍与测试音同长（0.7 秒），音间隔、音量、冷启动例外和开始作答的时机不变。

- One Note 的 Preview 改为直接点击的单音试听键。每个键对应当前所选音名与八度中的一个真实音高，例如 E4、F4、E5、F5；每次点击只播放该音，可以任意顺序或反复点击同一个音，不自动播放其他音。新点击替换上一个试听，播放期间标记对应音名、八度和试听键。音色选择、音域限制、试听不计分及切换设置/开始训练/切出页面时取消试听均保持原样。
- 两种乐器、两种作答方式的设置页使用相同的试听面板。普通版、单文件版及离线缓存同步更新；其他训练逻辑不变。

## 3.0.6 修复

- 答题界面下移：训练时音名、八度、Other、半音数字和乐器答题区整体靠近屏幕下方；不压缩按键尺寸，有必要时仍可纵向滚动。答后试听提示预留空间，避免按钮在试听时跳动。
- One Note 干扰音与目标音共用 0.7 秒的播放时长；仍为随机 6–8 个音，保留原音量、音间隔、音色选择与首题冷启动例外。计时只在目标音响起时开始，不从干扰音开始。
- 普通 One Note / Two Notes，无论 Buttons 或 Instrument，只要答错、八度错误或超时，就必须手动点击 Next 才会进入下一题；自动下一题只在完全答对时生效，重播与自由试听也不会重新开启错误题的自动推进。盲测的每道题均手动下一题，避免暂停状态泄露答案正误；结束后统一反馈。评分规则不变。
- 普通版、单文件版和离线缓存同步到 3.0.6，保留 3.0.5 的混合音色及学习音试听等功能。

## 3.0.5 改进

- 增加独立的 **Sound / 音色** 选项：钢琴、小提琴、混合。乐器界面决定显示和可操作音域；声音可以单独选择。One Note、Two Notes、Instrument、Buttons 和 Free Play 均使用该选项，切换模式或乐器界面后记住已选择的音色。
- **混合**：每道新题独立随机选择钢琴或小提琴音色。Two Notes 同一道题的两个音使用同一种音色；手动重播、答题反馈与本题试听保持原题音色。停止后可继续比较，也可更改音色再试听。Free Play 每次按音独立随机选择；单音题前的干扰音也按所选音色模式播放。
- **One Note 试听所选音**：在音名和八度设置下增加试听按钮，按音高从低到高播放当前所选音名与八度中可用的全部音。播放时显示音名、八度和音色，并标出对应选项；按钮可随时停止。混合模式按每个试听音随机选择音色。修改音名、八度、音色或模式，开始练习，或切出页面都会停止试听。没有可播放的已选音时禁用按钮。
- 试听不会产生题目或计分；与已有自由试听一样，会记录最近听到的已标注音，供之后的单音出题和休息后首音判断使用。历史记录保存实际题目音色，原有数据归属和备份兼容性保持不变。
- 普通版、单文件版和离线缓存同步到 3.0.5。Two Notes 无开场倒计时、答对重播、参考音同步，以及两种作答界面的答后自由试听均保留。

## 3.0.4 修复

- 普通练习答题后，Buttons 和 Instrument 共用试听逻辑。One Note 可点击任意音名或乐器实际存在的八度试听（初始为本题正确音，超出练习音域也可试听）；Two Notes 可点击当前显示的任意半音数字，播放对应的两个音，方向与本题一致，优先保留参考音，必要时平移至可演奏音域。试听保留原评分，暂停自动下一题，按 Next 继续。Stop 后保留按钮试听；盲测进行中仍不开放试听，停止后可以试听。Other 和 Not sure 无对应固定音高，不作为试听按钮。
- 普通版和单文件版同步，缓存版本更新。训练算法、评分与计时不变。

## 3.0.3 修复

- One Note 的 Other（其他音）改为醒目的正式作答按钮，固定在音名按钮或乐器上方；设置页面明确说明集外音无须判断具体音名或八度。集外正确/集内错误的原有分类评分不变。若当前出题池不含集外音，按钮仍可见但禁用。普通练习和盲测均适用；Two Notes 完全不变。

- One Note 的 Instrument 普通练习与 Two Notes 共用答题后自由试听：答对、答错或超时后可点击全部琴键或指板（包括训练音域以外），不重新计分；试听暂停自动下一题，按 Next 继续。Stop 后仍可自由演奏。盲测进行期间不开放试听，以保持测试无提示；停止后可自由弹奏。

## 3.0.2 修复

- Two Notes 开始即出题，无开场倒计时；第二音起算的作答限时和 One Note 的开场倒计时保持不变。
- Two Notes 乐器界面每题评分后全部琴键/指板位置均可自由试听（包括出题音域以外的音），参考音和正确/错误标记保留，不重复评分。点击试听时停止上一段声音并暂停本题自动下一题，按 Next 继续；不点击时自动下一题照旧。Replay 仍可完整重听本题，不解除试听暂停。
- 停止 Two Notes 后乐器仍显示，支持自由演奏。按钮作答模式的行为除取消开场倒计时外不变。普通版与单文件版同步。

## 3.0.1 修复

- Two Notes 答对后自动完整重播第一音与第二音（间隔及音长与出题一致），自动下一题等待反馈播放完毕；手动下一题和停止仍可立即操作。强化重播不会计作答题前的 Replay。
- 乐器界面在第一音的估计可听起点标记蓝色参考音；第二音起点才开放答题并计时。两个乐器均适用，Buttons 界面仍不显示参考音位置。
- 其他训练逻辑、设置、评分和存储格式不变。普通版与单文件版同步更新。

## 使用

解压后可直接打开 `single-file/index.html`（单文件版，含原始采样音源），或在原部署地址替换根目录 `index.html`、JS、CSS、`vendor/` 等文件。普通版支持 PWA；更新提示在训练外生效。建议先备份 2.8.11 的数据和文件。单文件在不同路径或浏览器中打开时不一定共享原数据。

## 三种模式

先选 **Sound / 音色**，再开始练习；此选项在自由演奏中也可使用。首次使用仍采用当前界面的默认音色，手动选择后会记住设置。

- **One Note**：选学习音名、八度和作答时限，直接开始无限单音训练。默认音名 F、八度 4/5；优先沿用旧 Focused AP 的学习设置（如可迁移）。Instrument 是琴键/指板作答，Buttons 是音名和八度作答。非学习音名统一按 Other 判分，音名与八度分开计分。盲测不提前反馈、不能重播，结束后显示成绩和答案。普通练习即时反馈，错误时重奏正确答案。
- **Two Notes**：选择半音数下限、上限（可选 Unlimited）和方向（上行/下行/随机），无限练习。默认覆盖完整乐器音域；每次进入重新恢复全音域，可以在折叠的音域设置手动缩小。Buttons 直接按半音数；Instrument 按第二个音位置，第一音用蓝色标记。可重播。音程过大或音域过窄无法满足相邻目标音名不同规则时提示调整。
- **Free Play**：所有可操作琴键或指板位置都能自由演奏，无题目、无课程。

钢琴 A0–C8（七层完整 88 键），小提琴 G3–E6（34 个不同音高、52 个指板位置）。新版统一按真实可操作指板范围出题，旧集中训练中小提琴更高的音域不再提供。两种作答方式使用同一个题目生成、音频播放、计时和记录控制器；默认 Buttons，分别保存单音/双音作答方式与限时。

## 训练规则

- 单音开始前 3 秒倒计时（双音直接开始）；单音在非冷启动首题及后续题之间默认随机播放 6–8 个采样干扰音（每个与目标音一样为 0.7 秒，可关闭）。题间音列独立于下一题。盲测休息后首题不播放干扰音。
- 相邻题目标音名严格不同。单音主动练习延续 2.8.11 的近期重复降权、概率性跨八度、集外干扰抽题；盲测在可用音名中随机抽取，不按学习集加权。两个学习音名的目标题比例约 60%，属于训练参数，不是经验证的最佳值。
- 两音练习在可用半音数及方向中随机抽题，对上一题音程降低抽中权重；无须在乐器上按位置也能答半音数。计时从第二音起算。
- 默认 1.3 秒（如已有设置则优先沿用），可填秒数，空白或 0 为不限时。计时从目标音发声起算。普通练习答对后自动下一题默认开启，也可关闭；答错（含八度错误及超时）须按 Next，盲测全部手动推进。允许随时停止，没有固定题数和晋级要求。

## 历史和迁移

训练成绩随作答保存。Statistics 折叠面板提供首听正确率、学习音命中率、集外误报、八度正确率、休息后首音统计、反应时间及备份/恢复。旧 AP/音程记录沿用原数据库；旧 RP 课程记录保留并计数，可导出。旧 Focused AP / Focused Interval JSON 备份可合并导入；新备份可包含两种乐器。旧课程等级、晋级进度及部分专用设置不再显示或沿用。原训练时长追踪和可选同步入口保留于 Statistics。

旧课程窗口和分级流程不再加载。为避免本次界面重构影响已有数据兼容及便于旧回归测试，部分旧源文件仍随包分发但不在新版活动页面中加载；旧文档仅供历史参考（`README-2.8.11-archive.md`）。

## 开发与验证

- `python build-single.py` 从普通版生成单文件版。
- `python tests/browser_grouped_layout.py index.html violin`（或 `piano`、`single-file/index.html`）验证两种模式、两种作答界面在 390×844、360×640、320×568 和 1280×800 下的整体布局、错误暂停、重播、下一题及停止。四组浏览器测试均通过。
- `python tests/browser_preview_mask.py index.html violin`（或 `piano`、`single-file/index.html`）验证手动试听、重复点击、无自动播放、3–4 个等时长干扰音和错误强制暂停。
- `python tests/browser_review_pause.py index.html violin`（或 `piano`、`single-file/index.html`）验证答题区位置、干扰音时长、错误强制暂停、重播后暂停、八度错误、超时、答对自动推进和盲测隔离。
- `node tests/test_unified.cjs` 验证统一抽题、相邻同名约束、E/F 周期性重复、音域及集外评分。
- `node tests/test_sound_routing.cjs` 验证新的音色路由、题目音色保持、试听音域和异步取消逻辑；此测试使用音频/时钟替身，不替代真实浏览器或听感验证。
- `python tests/browser_sound_options.py index.html violin`（或 `piano`、`single-file/index.html`）验证音色选择、学习音试听、重播/反馈/答后试听、Free Play、设置记忆及实际采样路由。默认使用 `/usr/bin/chromium`，可用 `EAR_TRAINER_CHROMIUM` 指定浏览器程序。
- `python tests/browser_unified.py index.html piano`（或 `violin`；单文件改用 `single-file/index.html`）为新版 Chromium 浏览器交互测试，需要 Playwright 与 Chromium。测试采用内存加载和模拟存储来源，不能代替实机/PWA 升级验证。
- `python tests/browser_interval_review.py index.html violin` 验证双音无开场倒计时、评分后自由试听、暂停/恢复自动下一题、Stop 隐藏答题区、Free Play 自由演奏及 AP 倒计时保留。
- `python tests/browser_interval_feedback.py index.html violin` 验证上一版双音重播与参考音同步。
- `python tests/browser_button_review.py index.html piano`（或 `violin`、`single-file/index.html`）验证两种模式的按钮试听、正确/错误/超时、自动下一题暂停、盲测隔离和停止后隐藏答题区；`node tests/test_button_review.cjs` 验证全部可用音域的试听音高及音程映射。
- 包含其他旧版回归测试，主要用于验证复用模块及历史算法；旧页面交互测试针对历史界面，不再是新版 UI 测试。

听觉训练效果以本人实际练习、跨日测试为准，模拟仅验证程序逻辑。音源授权见 [THIRD_PARTY.md](THIRD_PARTY.md)。
